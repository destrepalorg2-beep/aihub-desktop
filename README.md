# Ollama AI Desktop

Electron desktop приложение для управления Ollama Mobile AI Server.

## Запуск

```bash
cd desktop-app
npm install
npm start
```

## Сборка для Windows

```bash
npm run build
```

## Функции

- 🟢 System Tray с цветным статусом сервера
- 📊 Дашборд с метриками в реальном времени  
- 👥 Admin Panel: управление пользователями и подписками
- 🌐 Отображение IP-адреса для мобильного подключения
- 🚀 Автозапуск с Windows
- 💾 Управление настройками сервера
- 🦙 Статус Ollama и список моделей
